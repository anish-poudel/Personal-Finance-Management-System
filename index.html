Data and privacy

Sync status: local-only. This version stores data in this browser on this device. GitHub Pages hosts the application code, not your private transaction data. Data is not automatically synchronized between devices. Download JSON backups regularly and keep them somewhere secure. Before deleting records or restoring a file, the app creates a safety backup in this browser. No Firebase credentials or cloud-sync secrets are included.
